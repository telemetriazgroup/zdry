# Evolución 11 — vista de cliente y reglas de evaluación

**Fecha:** 2026-10-26

## Cambio

En el enlace del cliente y en «Ver como cliente» solo aparecen los tipos y almacenes que tienen unidades publicadas. No se muestra el orden por ISO o precio. Si el fabricante no está definido, la tarjeta no lo dice y el detalle sí muestra «No definido».

La ficha de catálogo abre el catálogo comercial. Muestra el promedio de evaluación cuando existe y, si el sistema cambió la condición, la condición anterior. En Evaluaciones se editan los puntos de cada nivel y las reglas para pasar de una condición a otra.
