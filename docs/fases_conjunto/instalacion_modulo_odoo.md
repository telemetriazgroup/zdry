# Instalar el bridge en Odoo.sh

Canónica: `zgroup/documentacion/instalacion_modulo_odoo.md`.

En Apps no se busca como aplicación. Tras el build **Connected**, en el Shell de Odoo.sh: `update_list` + `button_immediate_install` / `button_immediate_upgrade`. Menú: **Inventario → Configuración → Eventos ZDRY**.
